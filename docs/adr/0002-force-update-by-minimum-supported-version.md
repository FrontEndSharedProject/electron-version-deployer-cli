# 强制更新以最低支持版本表达，而非逐版本布尔开关

远程版本元数据通过可选的 `minSupportedVersion` 声明最低支持版本（Minimum Supported Version），客户端仅在本地版本低于它时进入强制更新（Force Update）。逐版本 `forceUpdate: boolean` 无法跨版本保持：1.1.0 标记强制、1.2.0 未标记时，仍停留在 1.0.x 的客户端会逃过强制更新；最低支持版本写在部署配置中随仓库持久化，后续普通发布天然沿用。`--force-update` 保留为「最低支持版本 = 本次发布版本」的简写，`--no-force-update` 表示本次不声明。

## Considered Options

- **逐版本布尔开关**：实现最简单，但强制语义随下一次普通发布丢失，与「本地版本过低」的领域定义不符。
- **部署时自动沿用远程已有的最低支持版本**：免配置，但最终写入值依赖部署时远程是否可达，属于隐藏状态；改为在生效值低于远程现值时走预部署检测门禁，由发布者显式确认。

## Consequences

- 生效值低于远程现值（含取消）且并非来自显式 CLI 参数时，预部署检测要求交互确认或 `--allow-min-version-downgrade`。
- `minSupportedVersion` 不得高于本次发布版本，否则更新到最新版的客户端仍低于下限，陷入强制更新循环。
- 不支持该字段的旧客户端会忽略它，强制更新只对已运行支持版本的客户端生效。
